An invented passport spread: the open passport of the Republic of Kavarra, a country that isn't there. Data page with a drawn portrait, personal details and machine-readable zone; facing page with the coat of arms, entry and departure stamps, a visa sticker and a circular date stamp. Everything is drawn in code — no images, no network, no randomness.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR` (or `./output` when unset). Two runs are byte-identical.
